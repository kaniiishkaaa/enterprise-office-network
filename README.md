# Enterprise Office Network

## Project Overview
This project is a simulation of an enterprise office network created using Cisco Packet Tracer. The main idea was to understand how a real office network is designed and how different devices communicate with each other in a structured way.

## What I did in this project
- Created multiple VLANs for separating departments
- Configured trunk links between switches
- Used VTP for VLAN management
- Set up Inter-VLAN routing for communication between different VLANs
- Configured DHCP for automatic IP assignment
- Used DNS for name resolution
- Added a web server for internal access

## Tools Used
- Cisco Packet Tracer

## Files in this project
- Enterprise-office-network.pkt (main simulation file)
- Topology.png (network diagram)

## What I learned
- How enterprise networks are structured
- VLAN segmentation and routing concepts
- Basic network services like DHCP and DNS
- How different network devices work together in a real setup
